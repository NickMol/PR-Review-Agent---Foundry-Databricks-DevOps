Setup Azure Databricks — end to end

---
Phase 1 — Azure: create the Databricks workspace (~10 min)

1. Go to portal.azure.com and sign in
2. Search for "Azure Databricks" in the top search bar → click the service
3. Click Create
4. Fill in the basics:
   - Subscription: select your subscription
   - Resource group: create new → name it e.g. rg-databricks-poc
   - Workspace name: e.g. databricks-poc
   - Region: pick one close to you (e.g. West Europe)
   - Pricing tier: Premium  ← required for Unity Catalog
5. Click Review + create → Create
6. Wait ~2 min for deployment to finish
7. Click Go to resource → Launch Workspace
   - Note the workspace URL (e.g. https://adb-xxxx.azuredatabricks.net) — you will need it later

---
Phase 2 — Databricks: enable Unity Catalog (~5 min)

Unity Catalog may already be enabled on newer workspaces. Check first:

1. In the workspace, click the catalog icon (left sidebar)
2. If you see catalogs listed (e.g. "main"), Unity Catalog is already active → skip to Phase 3
3. If not, go to accounts.azuredatabricks.net
   - Click your workspace → Enable Unity Catalog
   - Follow the prompts to assign a metastore (create one if none exists for your region)
   - Assign the metastore to your workspace

---
Phase 3 — Databricks: create the three catalogs (~5 min)

The bundle creates schemas and volumes automatically, but the catalogs themselves must exist first.

1. In the workspace → left sidebar → Catalog icon
2. Click Create catalog (top right)
   - Name: dev
   - Storage: leave default (uses metastore root storage)
   - Click Create
3. Repeat for uat and prd

You should now see dev, uat, and prd listed in the catalog explorer.

---
Phase 4 — Databricks: generate a PAT token (~2 min)

1. Top-right corner → click your profile icon → Settings
2. Left menu → Developer → Access tokens
3. Click Generate new token
   - Comment: azure-devops-poc
   - Lifetime: 90 days
4. Copy the token immediately — you will not see it again
   Store it ONLY in the Azure DevOps variable group (Phase 5). Never paste it into a file.

---
Phase 5 — Azure DevOps: update the variable group (~2 min)

1. Go to your Azure DevOps project → Pipelines → Library
2. Open the databricks-medallion variable group
3. Update DATABRICKS_HOST:
   - Value: https://<your-new-workspace-url>.azuredatabricks.net
4. Update DATABRICKS_TOKEN:
   - Click the variable → paste the PAT from Phase 4
   - Make sure the lock icon is enabled (secret)
5. Click Save

---
Phase 6 — First deploy (~5 min)

Trigger the pipeline by pushing a small change to the dev branch, or run it manually:

1. Azure DevOps → Pipelines → select your pipeline → Run pipeline → Branch: dev
2. The pipeline will:
   - Validate the bundle
   - Deploy (creates bronze/silver/gold schemas and the orders_landing volume)
   - Run the Databricks pipeline
3. After a successful run, upload the sample data to the volume:
   databricks fs cp data/sample_orders.csv dbfs:/Volumes/dev/bronze/orders_landing/sample_orders.csv
4. Trigger another run to process the file through Bronze → Silver → Gold
